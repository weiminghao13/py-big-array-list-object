BigArrayList

面向大数据量场景的惰性流式列表库。零运行时依赖，支持千万级数据的流式处理、并行排序、外部排序与分桶查找。

Python ≥ 3.10 零运行时依赖 mypy strict MIT License PyPI: bigarraylist
📖 API 参考文档 🏗️ 架构图

核心特性

🌊

惰性流式处理

所有算子返回 generator，数据按需计算，内存占用 O(1)。支持 map / filter / reduce / distinct / slice 等链式操作。

⚡

三级智能排序

根据数据量自动选择策略：10 万条以内直接排序，10 万~100 万分块并行排序，100 万以上自动落盘外部排序。

🔍

多种查找方式

支持线性查找、二分查找、并行查找和分桶索引查找。建桶一次，多次查询，海量数据也能秒级定位。

🧩

协作式多继承

_CoreBase 持有状态，各 Mixin 只声明方法，通过 MRO 协作。__slots__ 降低内存，_fresh_iter 保证算子互不污染。

🛡️

类型安全

全量泛型标注，mypy strict 模式零错误。disallow_untyped_defs + warn_return_any 全开，IDE 补全丝滑。

📦

零依赖轻量

纯标准库实现，安装包仅 45KB。不需要 numpy、pandas 等重型依赖，嵌入式环境和容器镜像都能轻松使用。

🚀 快速开始

# 安装 pip install bigarraylist
from bigarraylist import BigArrayList # 创建一个百万级数据流 data = BigArrayList(range(1_000_000)) # 链式惰性处理（全程不占内存） result = data.lazy() \ .filter(lambda x: x % 2 == 0) \ .map(lambda x: x * x) \ .take(10) \ .collect() # 智能排序（自动选择并行/外部排序） data.sort() # 分桶索引查找 data.build_buckets() idx = data.bucket_find(999999)
