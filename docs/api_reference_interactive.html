BigArrayList 用户接口类 bigarraylist/_api.py
继承: BaseBigArrayList
用户接口层。继承 BaseBigArrayList，在所有公共方法入口处做参数校验（类型+范围），然后转发给父类实现。 所有公共方法签名 100% 向后兼容。双 API 共存：旧方法返回裸 generator（不可链式），新方法 .lazy() 返回 LazyChain（可链式）。

_CoreBase[T] 核心基类 bigarraylist/core/base.py
继承: Generic[T] · 被 BaseBigArrayList 继承
核心基类。持有所有状态字段（__slots__）+ 迭代协议 + _fresh_iter 核心机制。所有算子 Mixin 通过 self._fresh_iter() / len(self) / self._get_config() 与本类协作，不直接访问私有字段。
方法参数返回值说明
▶__init__source: int | Iterable[T], *, config: BigArrayConfig | None = NoneNone构造核心基类

三种 source 分流：int（生成 N 个全 0）、Sized Iterable（零物化，直接用 len）、纯 Iterator/Generator（必须 list() 物化拿长度，且更新 __source 为物化后的 list）。

▶__len__（无）int返回数据总量

len(big) 返回构造时确定的数据总量。

▶__iter__（无）Iterator[T]返回 self（惰性迭代）

返回 self，让 for 循环调用 __next__ 逐个取值。不预读任何数据。

▶__next__（无）T取下一个元素

标准迭代器协议。耗尽抛 StopIteration。操作 self.__data（对外 for 循环专用）。

▶__getitem__index: intT随机访问（不支持）

主动抛 NotImplementedError。大数据不支持随机访问（要求全部物化进内存，与惰性流设计冲突）。要取第 N 个元素用 itertools.islice 流式跳过。

▶__contains__target: objectboolx in big 线性查找

用 _fresh_iter() 拿独立迭代器查找，不消费 self.__data。零副作用可重复调用。

▶_fresh_iter（无）Iterator[T]⭐ 核心机制：拿独立迭代器

返回一份基于原始 source 的全新独立迭代器。所有算子统一通过本方法拿独立局部迭代器，全程操作局部变量，绝不碰 self.__data。self.__data 只留给 __next__ 对外 for 循环用。这样算子之间零副作用，可重复调用。

▶_get_config（无）BigArrayConfig返回配置对象（供算子用）

返回实例的 BigArrayConfig，供各 Mixin 算子读取阈值。

▶_get_source（无）int | Iterable[Any]返回原始 source（供 copy 用）

返回原始 source 引用（不复制），供 BigArrayList.copy() 等需要构造新实例的场景使用。

▶cycle（无）Generator[T, None, None]无限循环迭代器

数据耗尽后从头再来，永不停止。while True: yield from self._fresh_iter()。必须自己 break。

▶_reverse_iter（无）Generator[T, None, None]反向迭代器

从尾到头逐个产出。int 源反转仍是全 0；list/tuple 走 reversed() 视图；generator 源抛 TypeError（已耗尽）。反向迭代天然要求物化源数据，这是反向语义的固有代价。

▶_copy_iter（无）Generator[T, None, None]复制迭代器

从头到尾逐个产出元素。全程操作 _fresh_iter()，不碰 self.__data。

▶_samplek: int, seed: int | None = NoneGenerator[T, None, None]蓄水池抽样（核心层实现）

直接放核心层（无需 Mixin），依赖 reservoir_sample 函数。从总量未知的流里随机等概率抽 k 个元素。
BaseBigArrayList 组合类 bigarraylist/core/base.py
继承: _CoreBase[T], CRUDMixin[T], StreamMixin[T], SortMixin[T], SearchMixin[T]
大数据惰性流基类。通过 cooperative multiple inheritance 组合核心协议 + 所有算子 Mixin。类体为空（pass），所有方法由 MRO 中的基类提供。对外 API 由 _api.BigArrayList 提供（继承本类 + 参数校验）。本类供"需要直接访问底层算子、不要参数校验"的场景使用。

LazyChain[T] 链式 API 类 bigarraylist/operators/stream.py
继承: Generic[T] · 由 StreamMixin.lazy() 创建
链式 API 包装器。每个算子返回新的 LazyChain，全程惰性，只有 .collect() / for x in chain 才真正消费。支持 .filter().map().distinct().slice().collect() 链式调用。distinct() 有大数据保护（set 达 10 万主动抛错，建议用 BigArrayList.distinct()）。

真正的低内存外部排序。两阶段算法：阶段1流式分块排序+落盘，阶段2多路归并。默认 streaming 模式（逐条 pickle.load，内存峰值 O(块数)），block 模式（整块 load，快 3~5 倍但内存≈数据总量）通过配置 opt-in。
函数参数返回值说明
▶external_sortdata: Iterable[T], total_count: int, *, config: BigArrayConfig | None = None, max_workers: int | None = None, key: Callable[[T], Any] | None = NoneGenerator[T, None, None]⭐ 低内存外部排序

阶段1：流式读 data → 攒够 chunk_size → pool.submit(sort_chunk).result() → 落盘临时文件。顺序提交牺牲并行度换内存安全。

阶段2：同时打开所有临时文件 → lazy 文件迭代器 → heapq.merge 多路归并 → 逐条 yield。

streaming 模式：阶段1逐条 pickle.dump，阶段2逐条 pickle.load，内存峰值 O(块数)≈32条元素。

block 模式：阶段1整块 dump，阶段2整块 load，速度快3~5倍但内存≈数据总量。

data — 数据源迭代器（建议来自 _fresh_iter）
total_count — 数据总条数（用于选块大小）
config — BigArrayConfig，None 用默认
max_workers — 阶段1排序进程池并行度
key — 排序键函数，None 按元素本身排序
返回生成器，按 key 的非降序逐条产出已排序元素。
reservoir_sample() 模块级函数 bigarraylist/algorithms/sample.py
蓄水池抽样算法。从总量未知的流里随机等概率抽 k 个元素。前 k 个直接入池，第 i 个（i>k）以 k/i 概率替换池中随机元素。数学保证每个元素被选中概率都是 k/N。
函数参数返回值说明
▶reservoir_sampledata: Iterable[T], k: int, *, seed: int | None = NoneGenerator[T, None, None]⭐ 蓄水池抽样

时间 O(N) 一遍流式扫描，空间 O(k) 蓄水池大小，无需预知总量 N。

data — 数据源迭代器
k — 要抽取的样本数（>=1）
seed — 随机种子，None 系统随机；传 int 可复现
返回生成器，逐个 yield 抽中的 k 个元素。
